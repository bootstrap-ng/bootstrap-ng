Angular 22 · Bootstrap 6 alpha

Bootstrap components, built for modern Angular

bootstrap-ng gives you native Angular components for Bootstrap 6. They use signals, standalone imports and zoneless change detection. They render the same markup as Bootstrap, so its CSS and theming work as documented.

Signals first

Inputs, outputs and two-way bindings use the signal APIs. Every component is OnPush and works without zone.js.

Real Bootstrap markup

Attribute selectors such as <div bsAlert> keep the DOM exactly as Bootstrap expects. No wrapper elements break its CSS.

Platform native

Dialogs use <dialog> and accordions use <details>, like Bootstrap 6. The browser does the hard work.

No Bootstrap JavaScript

Behavior is written in Angular, so there is no jQuery-era plugin layer and no DOM fighting.
