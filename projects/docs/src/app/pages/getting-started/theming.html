Theming

Theme colors, light and dark color modes, and customizing Bootstrap in an Angular application.

Theme colors

Color modes

Bootstrap 6 builds its colors with the CSS light-dark() function, so every page follows the visitor's system setting for light or dark mode with no extra code. bootstrap-ng components use Bootstrap's color tokens, so they switch with the page.

Popups such as the datepicker calendar open in the top layer, outside the element they belong to. The datepicker's colorMode input forces a mode for its calendar.

Customize with Sass

To change Bootstrap's design tokens at build time, import its Sass source in src/styles.scss instead of adding the compiled CSS to angular.json. Pass the tokens you want to change with with (), and Bootstrap merges them with its defaults:

The Angular CLI resolves bootstrap/scss/bootstrap from node_modules, so no extra configuration is needed. To add a theme color of your own, pass a $theme-colors map the same way.
