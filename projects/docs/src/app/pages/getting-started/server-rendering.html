Server-side rendering

Use bootstrap-ng with server-side rendering, prerendering, hydration and zoneless change detection.

Server-side rendering and prerendering

bootstrap-ng works with Angular's server-side rendering and build-time prerendering. Add them to an application with the Angular CLI:

Components render Bootstrap's markup, classes and ARIA attributes on the server, so the page is styled and readable before JavaScript loads. Work that needs a browser, such as measuring elements, positioning popups, opening a <dialog>, moving focus or starting a carousel, runs in afterNextRender() or afterRenderEffect(), which Angular skips on the server.

So anything that needs the browser, such as a modal dialog's backdrop and focus trap, starts once the page hydrates.

Zoneless change detection

bootstrap-ng does not need zone.js. Components keep their state in signals, so they update with zoneless change detection, which is the default for new Angular applications. The library's tests and this site run without zone.js. Applications that still use zone.js work as well.
