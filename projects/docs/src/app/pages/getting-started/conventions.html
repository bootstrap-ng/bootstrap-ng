Conventions

The rules that every bootstrap-ng component follows.

Bootstrap markup, not wrappers

Most components use attribute selectors on the element that Bootstrap styles. The rendered DOM is the same as in Bootstrap's own documentation, so selectors such as .accordion > .accordion-item keep working.

Themes and variants

Bootstrap 6 replaces color-named classes such as .btn-primary with a variant class and a .theme-* class. bootstrap-ng exposes these as separate variant and theme inputs. The themes are primary, accent, success, danger, warning, info, inverse and secondary.

Each component also has its own entry point, named after its folder, such as bootstrap-ng/button or bootstrap-ng/datepicker. Importing from bootstrap-ng gives the same bundle: a component that only lazy routes use is loaded with those routes, not up front.

Accessibility

Components set the ARIA roles and states that Bootstrap documents, such as aria-expanded on collapse toggles and role="progressbar" on progress bars. You still give labels: for example, aria-label on icon buttons and progress bars. See Accessibility for keyboard support, focus management and live announcements.
