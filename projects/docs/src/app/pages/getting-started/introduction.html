Introduction

Add bootstrap-ng to an Angular application and use your first component.

bootstrap-ng targets Bootstrap 6, which is in alpha. Class names and markup can change before the stable release. bootstrap-ng follows each Bootstrap 6 pre-release.

Requirements

  • Angular 22 or later
  • Bootstrap 6 CSS

bootstrap-ng does not use Bootstrap's JavaScript. Do not add bootstrap.bundle.js to your application. It would handle the same elements twice.

Install

Bootstrap 6 is published under the next tag until its stable release, so a plain npm install bootstrap would install Bootstrap 5. Floating UI positions tooltips, popovers and menus, as it does in Bootstrap.
