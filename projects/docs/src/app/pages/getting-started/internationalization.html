Internationalization

Translate the text that components render, show dates in any locale and lay out pages from right to left.

Overview

bootstrap-ng has no translation files and no global language setting. Most of what users read is your own content, and the few strings that components render themselves, such as a close button's accessible name or a datepicker's month names, come from inputs or from the browser's Intl API. That means it works with Angular's built-in i18n and with runtime translation libraries alike.

  • Built-in labels default to English. Each has an input to replace it, and you can translate them for the whole app with the global configuration.
  • The calendar and datepicker format month names, weekdays and dates with Intl.DateTimeFormat in Angular's LOCALE_ID, or in the locale you give them.
  • Bootstrap 6's CSS uses logical properties, so one stylesheet works for both left-to-right and right-to-left pages, and components follow the dir attribute.

Dates and locales

Set locale on a datepicker or an inline calendar to choose the language of its month names, weekdays and the dates it shows. Each calendar below also sets its own previous and next month labels and the first day of the week:

Without locale, calendars and datepickers use Angular's LOCALE_ID, so they show dates in the same language as the rest of your app, such as dates shown with DatePipe. LOCALE_ID is en-US unless your app or a localized build sets it. To use another locale for every calendar and datepicker, set it in the global configuration, or bind [locale]="undefined" on one to follow the browser's language:

A datepicker on an input shows the selected date as an ISO date (YYYY-MM-DD), so what it shows can also be typed. A datepicker on a button shows it in the locale's medium date style. First day of the week and week numbers

Weeks start on Monday by default. Set firstWeekday to 0 to start them on Sunday, as is usual in the United States, Canada and Japan. The first day of the week isn't part of the locale you pass, so set it alongside locale. Where browsers support Intl.Locale.getWeekInfo(), you can read it from the locale:

Add weekNumbers to show a week number before each week. Weeks are numbered with ISO 8601 by default, as is common in Europe; set weekNumbering="simple" to make week 1 the week that holds 1 January instead. Translate the week column's accessible name with weekLabel. See Week numbers on the datepicker page.

With Angular i18n

For function inputs and strings in TypeScript, use $localize:

A localized build sets LOCALE_ID for each language, so calendars, datepickers and the file dropzone's file sizes are already in the same language as the rest of the build. Translate the labels of the global configuration with $localize too, so every component's built-in text is translated in one place. With a runtime library such as Transloco or ngx-translate, bind the same inputs to its translated strings instead.
