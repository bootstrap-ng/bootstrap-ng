Quickstart

Create a new Angular application with bootstrap-ng and build a small page with a dialog and a toast.

1. Create an application

You need Node.js and npm. Create an application with the Angular CLI and choose Sass for styles:

2. Install bootstrap-ng and Bootstrap

Bootstrap 6 is published under the next tag until its stable release. Floating UI positions tooltips, popovers and menus.

3. Add Bootstrap's styles

Import Bootstrap at the top of src/styles.scss:

Do not add Bootstrap's JavaScript. bootstrap-ng implements all of its behavior in Angular.

4. Build a page

Replace src/app/app.ts with a component that imports the parts it uses:

And replace src/app/app.html with its template:

The button opens a native <dialog>, which traps focus and closes with Escape. Saving closes it and shows a toast through BsToaster.

5. Run it

Open http://localhost:4200 and select Edit name.
