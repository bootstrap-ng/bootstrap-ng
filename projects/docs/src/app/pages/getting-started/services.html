Services and helpers

The services, functions and types that bootstrap-ng exports besides its components.

BsToaster

Shows toasts from code, without a toast in your template. The toasts stack in a fixed .toast-container that is added to the page the first time a toast is shown.

See Toasts for every option, themes and templates with actions.

BsLiveAnnouncer

Reads a message out to screen reader users through visually hidden live regions that stay on the page. Use it for changes that happen without moving focus, such as search results updating. Toasts and the carousel already announce through it.

See Accessibility for why a region that stays on the page is announced more reliably than one added with its text.

BsIconRegistry

The icon libraries that bs-icon loads from, and a cache of the icons it has loaded. bootstrap (the default), font-awesome, material, modus and phosphor are built in and load from jsDelivr. Set the default library and add your own with provideBsIcons(), self-host a built-in set by passing a baseUrl to its factory, such as bootstrapIcons(), fontAwesomeIcons(), materialSymbols(), modusIcons() or phosphorIcons(), or bundle icons as SVG markup in a library’s icons. Bundled icons need no request and render on the server; each factory takes icons too, which are used before its files.

To self-host, install the icon set’s npm package and copy its SVG files into your build with an assets entry in angular.json, then pass the output path as baseUrl. Use the package folder that holds the set’s variant folders: bootstrap-icons/icons, @fortawesome/fontawesome-free/svgs, @material-symbols/svg-400, @trimble-oss/modus-icons/dist or @phosphor-icons/core/assets, with **/*.svg as the glob for sets that have variants.

To import an SVG file as text, as logo.svg above, declare its type once in your app.

See Icon for every built-in library and its variants.
