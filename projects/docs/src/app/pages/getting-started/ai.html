llms.txt

This site publishes its docs in the llms.txt format, generated from the pages on every build, so they match the current release:

  • llms.txt lists every page with a short description and a link.
  • llms-full.txt has every page in full, with its example code and API tables, as Markdown.

Agent skills

The bootstrap-ng repository has agent skills that teach coding agents, such as Claude Code, Codex and GitHub Copilot, how to work with bootstrap-ng. Add them to your project with the Skills CLI:

The bootstrap-ng-install skill adds bootstrap-ng to an Angular application: it installs the packages, adds Bootstrap's CSS, imports components and sets up global configuration and icons, then checks the result.
